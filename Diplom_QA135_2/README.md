Дипломный проект: Автоматизация тестирования (API и UI)

Данный проект предназначен для автоматизированного тестирования пользовательского интерфейса (UI) и программного интерфейса (API) сервиса Кинопоиск.

Тесты реализованы с использованием фреймворка Pytest, библиотеки Playwright для работы с браузером и библиотеки Requests для API-запросов.
Отчеты о прохождении тестов формируются с помощью Allure Framework.

Технологический стек

Язык программирования: Python 3.14+

Фреймворк тестирования: Pytest

UI Автоматизация: Playwright

API Автоматизация: Requests

Формирование отчетов: Allure Pytest

Линтер (проверка стиля): Flake8

Структура проекта

Diplom_QA135_2/
├── tests/
│   ├── main_page.py      # Page Object модель для главной страницы

└── README.md             # Документация проекта


Инструкция по установке

Клонируйте репозиторий и перейдите в папку проекта:

cd Diplom_QA135_2


Создайте и активируйте виртуальное окружение Python:

На Windows:

python -m venv venv
venv\Scripts\activate


На macOS/Linux:

python3 -m venv venv
source venv/bin/activate


Установите основные зависимости проекта:

pip install -r requirements.txt


(Опционально) Установите инструменты для разработки и линтер:

pip install -r requirements-dev.txt


Установите браузеры для работы Playwright:

playwright install

Конфигурация и безопасность

Конфиденциальные данные (токены, логины, пароли, API_KEY) вынесены в локальный файл .env (не попадает в репозиторий).
При первом запуске создайте файл .env в корне проекта и запишите необходимые переменные окружения (например, API_KEY=your_api_key).


Запуск тестов

1. Запуск всех тестов в проекте

pytest


2. Запуск только UI-тестов

pytest -m "ui"


3. Запуск только API-тестов

pytest -m "api"


4. Проверка стиля кода (Линтинг)

Для проверки соответствия кода стандарту PEP 8 запустите:

flake8 tests/


Генерация и просмотр отчетов Allure

Способ 1. Автоматический сбор и открытие отчета в браузере

Запустите тесты с сохранением результатов, а затем сгенерируйте и откройте отчет одной командой:

pytest --alluredir=allure-results
allure serve allure-results


Способ 2. Генерация статических HTML-файлов отчета

Если вам необходимо сохранить отчет в виде папки с готовым веб-сайтом:

pytest --alluredir=allure-results
allure generate allure-results -o allure-report --clean
allure open allure-report
